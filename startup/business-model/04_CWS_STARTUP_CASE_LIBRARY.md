# CWS Startup Case Library

Status: research notes. Re-check external sources before using any case as proof.

## Early-stage startup lessons
- first prove real value with a small group of users;
- direct Founder interaction with early users can accelerate learning;
- organic word-of-mouth is valuable when it comes from genuine product satisfaction;
- growth loops should amplify a working product rather than hide weak retention.

## Dropbox-style lesson
Product-native rewards can be more useful than generic points. CWS candidate: Render Credits.

## Transaction-referral lesson
A stronger referral event is a verified paid job rather than a click, share or signup.

## Uploaded chair-event transcript lesson
The reusable idea is cross-subsidy: an offer that feels free to the user can be funded by value created elsewhere in the business system. For CWS, this is a hypothesis to test through margins, credits, idle capacity or later ecosystem revenue.

## Rule
Startup cases are idea generators, not templates. Extract the mechanism, define a CWS hypothesis, sandbox it, measure it, then promote, iterate or reject.
