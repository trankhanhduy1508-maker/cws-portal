# CWS Free Render Economics

Status: sandbox research, not approved pricing.

## Current conclusion
A broad Free Compute Pool is deferred for MVP because early CWS has no accumulated subsidy pool and should first prove willingness to pay.

## Core hypothesis
Free render can become viable later only when it is funded by real economics, for example:
- contribution margin from paid jobs;
- lower-cost idle/off-peak host capacity;
- later external sponsor/partner revenue after CWS has meaningful user distribution.

## Example cross-subsidy hypothesis
Illustrative only:
- customer paid compute-hour: 6,000 VND;
- host payout: 4,000 VND;
- gross spread before other variable costs: 2,000 VND.

A portion of verified contribution margin could later be allocated to a Free Compute Fund, while the rest remains with CWS.

Important: `6,000 - 4,000` is not automatically net profit. Other usage-linked costs must be deducted first.

## Free tier guardrails if ever tested
- no guaranteed SLA;
- only uses eligible idle/surplus capacity;
- paid work has priority;
- quota is bounded by a real economic budget;
- fund exhaustion closes or delays free capacity rather than creating an unfunded promise;
- free usage must not degrade paid-customer performance.

## Later flywheel hypothesis
paid usage -> contribution margin -> bounded free/credit budget -> new user experiences CWS -> some users later become paid -> additional contribution margin.

If free-to-paid conversion does not occur or free workload cannibalizes paid capacity, reject or redesign the experiment.
