# CWS Backend

Backend NestJS cho CWS Customer Portal — thay thế `mockBackend.js`.

Xem chi tiết:
- BACKEND_SETUP.md — hướng dẫn deploy đầy đủ
- API_DOCUMENTATION.md — toàn bộ endpoint
- CHANGELOG.md — lịch sử thay đổi + giới hạn đã biết

## Chạy nhanh

```bash
npm install
cp .env.example .env   # điền giá trị thật
npm run build
npm run start
```
